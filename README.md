# 📊 Finance Performance Dashboard (Power BI)

## 📌 Project Overview
This project presents a financial performance dashboard built using Power BI to analyze revenue, profit, and business performance.

## 🎯 Objectives
- Track revenue and profit performance
- Analyze growth trends over time
- Compare actual performance with expected targets (variance analysis)
- Identify top-performing products and regions

## 📊 Key Metrics
- Total Revenue
- Total Profit
- Profit Margin (%)
- Revenue Growth (%)
- Revenue Variance & Variance (%)

## 🛠 Tools & Technologies
- Power BI
- DAX
- Data Modeling

## 📈 Features
- Interactive dashboard with slicers (Year, Country, Segment)
- Time intelligence calculations (Year-over-Year growth)
- Conditional formatting for variance analysis (Red/Green indicators)
- Clean and user-friendly layout
